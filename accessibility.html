Accessibility statement

We want this website to work for everyone – also for people who use a screen reader, only a keyboard, a phone, a big zoom level, or a browser with JavaScript turned off.

Conformance status

The course asks for WCAG 2.1 level A. We aimed higher: the website aims to meet WCAG 2.1 level AA of the W3C Web Accessibility Initiative (WAI). Our tests found no errors at level AA; the known limits are listed below.

What we did

  • Semantic HTML5 with landmarks (header, navigation, main, footer), one h1 per page and no skipped heading levels.
  • WAI-ARIA only where HTML has no element of its own: tabs, toggle buttons, live status messages and form errors.
  • Everything works with the keyboard; the focus is always visible and never hidden behind the sticky menu.
  • Text contrast of at least 4.5:1, also for text on photos.
  • All content can be read with JavaScript turned off.
  • Pages work from 320 px wide and at 200 % zoom without scrolling sideways.
  • English, Italian and German pages, each with the correct language set for screen readers.
  • Animations are switched off when the visitor prefers reduced motion.

Known limitations

  • The map comes from OpenStreetMap; we cannot change it. The same route information is written as text under "Getting there" on the Plan page.
  • The Italian and German texts have not yet been checked by a native speaker.

Feedback

If something does not work for you, please tell us through the contact form. This statement was written on 26 November 2026.
